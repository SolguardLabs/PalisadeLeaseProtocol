# PalisadeLeaseProtocol

![banner](./assets/banner.png)

PalisadeLeaseProtocol is a Solidity and Foundry implementation of a DeFi lease market for
productive positions. Owners retain principal in a vault while lessees receive temporary rights to
the rewards generated by listed positions.

The protocol models a full leasing lifecycle:

- `ProductiveVault` custodies principal and issues position tokens.
- `RewardEscrow` receives harvests and maintains a global reward index.
- `PalisadeLeaseMarket` lists, opens, renews, and settles leases.
- `LeasePricingOracle` calculates lease pricing from duration and utilization signals.
- `LeaseLedger` accounts for proceeds, fees, and settlement activity.
- Lens contracts expose solvency, continuity, and attribution views for operators.

## Requirements

- Foundry (`forge`, `cast`, `anvil`).
- Git Bash or WSL for `scripts/*.sh` on Windows, or direct Foundry commands from PowerShell.

## Usage

```bash
forge build
forge test -vv
bash scripts/ci.sh
```

## Architecture

```text
src/
  accounting/     # Lease proceeds and fee accounting
  interfaces/     # Public protocol interfaces
  libraries/      # Math, time windows, lifecycle, and reward attribution helpers
  market/         # Lease market and offer book
  policy/         # Optional risk controller
  pricing/        # Deterministic pricing oracle
  rewards/        # Reward escrow with a global index
  security/       # Access control, pausable, and reentrancy guard modules
  token/          # NFT-like productive position token
  vault/          # Principal custody vault
  views/          # Operator and accounting lenses
test/
  PalisadeLeaseMarket.t.sol
```

## Review Notes

Public tests cover listing, opening, renewal, settlement, harvest accounting, policy limits, and
operator views. Reviewers should inspect reward-index checkpointing, lease beneficiary transitions,
fee accounting, and settlement invariants across lifecycle operations.
